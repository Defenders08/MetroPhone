## 3. Текущая механика листания — КОЛЬЦО (бесконечное)

- `offset` без границ; **`MPWrapRing(x, margin)`**: fmod в [−margin, 1280−margin).
  margin = ширина элемента: страницы 320, заголовки 300, пары 130, квадрат 180.
  Заворот — только когда элемент полностью за экраном (иначе были наезды/дыры — см. §6).
- **applyBody** каждый кадр: страницам `layer.position = (wrap(i·stride − offset) + stride/2, home.y)` — **НИКОГДА не frame** (setFrame сбрасывает bounds.origin скроллвью → слетает вертикальный скролл); параллакс — `layer.transform = translate(0.4×m)`; заголовки/пары — frame по своему wrap (у них нет трансформа).
- Квадратный прогресс таймера — `_timerSquare` (UIView + 2 CAShapeLayer) **на корне пивота** (не на странице!), кадр в applyBody: `(3·stride − offset + 75, 146, 170, 170)`, виден только когда Таймер спереди **и отсчёт идёт** (`[timer running]`), strokeEnd = `[timer progress]`.
- Страницы 2–3 (Секундомер/Таймер): `scrollEnabled = NO`, кадры положительные (пикер (0,0,320,164), дисплей (16,0,288,72), кнопки by = 176/80), header-пары только на стр. 0–1.
- Состояние таймера → пивот: колбэк `mpOnStateChange(running)` → `[pivot syncTimerSquare]`.

## 5. Отладочный арсенал (через `/var/mobile/Library/Caches/metrophone/shot.request`)

- `echo 'cslow N' > …shot.request` — медленный (2.5 с) переход на вкладку N, снимать нашими кадрами (`dev.sh` → shot-prefs.png) — чистые кадры без камерных артефактов.
- `cadd` / `cdel` — добавить/убрать тестовые города Paris/Rome/Madrid (**сейчас они в списке юзера**).
- `cscroll 0..1` — программная вертикальная прокрутка фронтальной страницы.
- `dump` — дамп дерева вьюх в `dump-prefs.txt` (тянуть `dev.sh pull`).
- Кадры: `tools/dev.sh` (install/log/cmd/pull). **Железные скрины юзера** — через `afcclient get DCIM/100APPLE/IMG_N.PNG` (статус-бар в shot-prefs НЕ попадает!).

## 6. Открытые вопросы / что проверить Клоду

1. **Звонок будильника** — никогда не проверен (нотификации наши, формат скопирован).
2. **Пальцевая прокрутка и свайпы после кольца** — программная прокрутка верифицирована, тач — нет.
3. **Синяя полоса** — если юзер выключит «Режим модема» и она останется — копать (пока считаем системным индикатором раздачи).
4. Тестовые города Paris/Rome/Madrid в списке юзера — убрать (`cdel` или вручную).
5. Долгий список кругов секундомера — contentSize растёт, но не проверен.

## 7. Грабли-уроки (критичные)

- `setFrame:` на UIScrollView **сбрасывает bounds.origin** → вертикальный скролл слетает; двигать только `layer.position`.
- Прямые CAShapeLayer-саблои на скроллвью рендерятся с непредсказуемым сдвигом (bounds.origin гуляет) → важное не на слой страницы.
- Лимит текстуры A4 **2048×2048** — растеризация лент целиком давала пустой слой; постранично (320 → 640 px @2x) — ок.
- Ребёнок вне bounds родителя виден, но НЕ тапабелен (hitTest).
- Контейнер-UILabel со subviews обязан иметь `text = @""` (иначе двоение).
- ARC (`-fobjc-arc`), `make` однопоточно, `THEOS=$HOME/theos`, `make -j4` виснет.
- Сборка → `tools/dev.sh install` (сам ставит новейший deb, killall внутри) — Часы в фоне держат старый dylib: после установки **обязательно killall MobileTimer**.
- Скрины юзера: `afcclient get DCIM/100APPLE/IMG_N.PNG`; свёрка вёрстки — python PIL, pt = px/2.
- Пиксельные замеры железных скринов — единственная правда по статус-бару и «странным» артефактам (камера телефона даёт двойные экспозиции).

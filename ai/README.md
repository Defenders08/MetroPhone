# ai/ — материалы для ИИ-ассистентов

Всё, что нужно ИИ для работы над проектом: промпты, планы, контекст, референсы.

| Файл | Что это |
|---|---|
| `PROMPT-OSNOVA.md` | базовый промпт проекта — основа для новых сессий |
| `HANDOFF.md` | текущее состояние и «что дальше» — читать в начале сессии |
| `DESIGN-NOTES.md` | дизайн-заметки: плитки, локскрин, иконки |
| `FIX-PLAN.md` | план исправлений по «Настройкам» |
| `SETTINGS-AUDIT.md` | аудит страницы настроек |
| `AUDIT-QUESTIONS.md`, `AUDIT-QUESTIONS-2.md` | опросники для аудита |
| `MetroPhone-плитки.html` и соседние | HTML-прототипы плиток/иконок (визуальные референсы) |
| `audit-survey.html` | HTML-опросник аудита |
| `references/` | PNG-референсы иконок iOS и Windows Phone (бывшая `assets/`) |

Как собирать и ставить твик — в корневом `README.md` и `AGENTS.md`.

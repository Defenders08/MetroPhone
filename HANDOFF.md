# MetroPhone — контекст работы за 26–27 октября 2026

## Проект
Джейлбрейк-твик: тема Windows Phone (Metro) для **iOS 6.1.3 на iPhone 4**.
Путь: `/Users/ash/Documents/Проекты/MetroPhone`. Theos, Logos, ARC, armv7+armv7s, min iOS 6.0.
Хуки только в SpringBoard и Preferences; остальные процессы не трогаются.

Сборка: `export PATH="/opt/homebrew/bin:$PATH"; export THEOS="$HOME/theos"; make package FINALPACKAGE=1`
(без `/opt/homebrew/bin` в PATH падает на `ldid`). Пакет — `packages/ru.ash.metrophone_<ver>_iphoneos-arm.deb`.

**Контролы (0.20.89).** По референсу WP 8.1 (text box / push button / check box / radio):
поля оставлены тёмными; кнопки — **акцентный текст без рамки** (вариант с белой
рамкой-плашкой из 0.20.86 отклонён — не язык проекта); выбор — **белое радио**
16×16 (кольцо 1,5 pt, точка 6 pt) вместо синей галочки iOS, правый край 304 pt.
Попутно найдено: строки-действия были белыми, потому что `layoutPSTableCell`
каждый проход возвращал заголовку белый цвет и затирал акцент — теперь цвет
выбирается по типу строки (`PSButtonCell` → акцент).

**Выход со страниц вне PS (0.20.90–0.20.92).** У Spotlight, «Профилей» и сертификата
шапке не назначался `backTapped` — стрелка была, выхода не было. Теперь общий
`MPSettingsGoBackFromTable` (делегат таблицы → навбар в окне → pop/dismiss, результат в журнале).
Там же: ручки перетаскивания больше не скрываются правилом «без иконок», рисуются
свои три штриха и ставятся последним проходом. Команда `back` в отладочном канале.

**Панели поиска (0.20.93–0.20.95).** «Часовой пояс» был тупиком: навбар скрыт с прошлой
страницы, а шапки у `TimeZonePane` нет. Теперь такие панели получают шапку с выходом
и тёмное оформление (поле 16…304, таблица без разделителей), а для любой страницы
без нашей шапки есть страховка: через 0,4 с показывается родной навбар.

**Шапка панели в окне (0.21.1).** При клавиатуре контроллер сдвигает вью вверх — шапка,
лежавшая внутри, уезжала и экран становился пустым. Теперь шапка панели живёт в окне
(тег 'MPH1'), а кадр поля 16…304 держит хук на `layoutSubviews` самой панели.
Хук `becomeFirstResponder` для тёмной клавиатуры отклонён — сбивал фокус.

**Тап по шапке (0.21.3).** Жест `UITapGestureRecognizer` на шапке не срабатывал (hit-test
попадал в шапку, а вызова не было). Поверх шапки — прозрачная `UIButton` с тем же
действием и защитой от двойного срабатывания. Команда `hit <x> <y>` в канале
показывает, кто получит тап.

**Клавиатура на панели (0.21.9).** С клавиатурой поверх поднимается `UITextEffectsWindow`
с чёрной подложкой и накрывает окно приложения. Шапка панели теперь в своём `UIWindow`
с `windowLevel = 1050` (`0,20 320×96`) — выше клавиатуры, всегда видна и нажимается;
прячется в `viewWillDisappear`. `reloadInputViews` для тёмной клавиатуры запрещён:
делает подложку непрозрачной и снова закрывает контент.

**Панель под шапкой (0.21.13).** Контроллер при фокусе возвращает панель на `y=0` —
поле и таблица уезжают под шапку. Теперь `setFrame:` панели принудительно держит
`y=96` и высоту `родитель − 96`, в layout возвращается `alpha=1/hidden=NO`.
Для проверки добавлены `sshot` (снимок экрана целиком), `search on|off`, `wins`, `hit`.

**Страница сертификата («Основные → Профили», 0.20.85).** Имя, статус и «Удалить» живут
не в `contentView`, а в `MCDetailsHeaderContentView` (родной layout центрирует блок: x=97,
ширина 191 — отсюда обрезка «Hanabi's Updated Ro…»). Статус — `MCUIGradientLabel`, не UILabel.
Высоты строк задаёт `MCConfigurationDetailsController`: 109 / 202 / 44 pt, а с шапкой 96 + 16
это 467 при экране 460 — нижняя строка обрезалась. Теперь: блок растянут на 288 pt от 16,
имя 24 pt Light, статус 13 pt (цвет не трогаем — индикатор), «Удалить» акцентом 15 pt Medium,
шапке 89 (в ячейке 90), строке 56, пустое описание сворачивается в 0. Важно: динамические хуки
ставятся через `class_addMethod`/замену СВОЕГО метода — `class_getInstanceMethod` +
`method_setImplementation` на неунаследованном `layoutSubviews` подменял метод UIView
для всего процесса (этим и объяснялись скачки кадров).

**«Дата и время» (0.21.14–0.21.18).** Экран `DatePane` оказался не
`PSListController`, а `PSEditingPane` (UIView) внутри `DateController` — общий слой

полосой выбора. Картинки барабана iOS 6 пересобирает на каждом лейауте, поэтому
гасятся из хука `_UIDatePickerView`, а не из `DatePane`. Разбор — `SETTINGS-AUDIT.md`.

**«Обновление ПО» (0.21.19–0.21.28).** Контроллер — подкласс `PSListController`,

Текущий аудит: 27.10.2026 · iOS 6.1.3 (iPhone 4) · старт с версии 0.20.18.

Метод: статический разбор всех хуков + живая проверка на устройстве через отладочный
канал (`echo <cmd> > /var/mobile/Library/Caches/metrophone/shot.request`; команды
`url prefs:root=…`, `dump`, `specs`, `scroll 0..1`, снимки `shot-prefs.png`), журнал
`/var/mobile/Library/Preferences/metrophone.log`, крэши `/var/mobile/Library/Logs/CrashReporter/`.

## Правила оформления (НЕ менять — осознанные решения)

- В строках нет иконок вообще (решение 27.10); текст по левому краю 16 pt.
- Аксессуар «›» — белый шеврон-глиф 0xe69b; назад — шеврон «‹» в шапке (акцент).
- Шапка страницы: 52 pt Thin строчными (бренды — «Wi-Fi», «iCloud» — в своём регистре).
- Строки 24 pt Light, подзаголовки/значения 13 pt серые, высота строки 56 pt.
- Тумблер WP 46×22; ползунок — линия 3 px с белым квадратным бегунком 14×14.
- Исключения по страницам: CyDown (по классу), Auxo (по заголовку) — штатный вид.
- «Настройки» всегда открываются в корень при повторной активации.

## Чек-лист контролов и функций

- [ ] Тумблеры: тап, программное setOn (страница, меняющая состояние сама), WP-вид.
- [ ] Ползунки: громкость (Звуки), яркость, RGB на «Цветах»; растяжка на всю ширину.
- [ ] Поля ввода: пароль Wi-Fi (тёмная клавиатура, белый текст).
- [ ] Шевроны «›» (Wi-Fi/Bluetooth-диски), зона нажатия, положение 16 pt от края.
- [ ] Заголовки групп: двоеточия сняты, ширина в пределах экрана.
- [ ] Футеры: высота по тексту, кириллица не обрезается.
- [ ] Переходы назад/вперёд: шеврон в шапке, быстрая навигация, модальные страницы.
- [ ] Позиция прокрутки при возврате; зазор под шапкой 30 pt.
- [ ] Смена акцента на «Цветах» — живое обновление открытых страниц.
- [ ] Возврат в корень при повторной активации приложения.
- [ ] Стресс: 20–30 быстрых входов/выходов из разделов — без крэшей и утечек.

## Найденные баги (статический анализ, до живой проверки)

1. **Тумблер не синхронизируется при программном `setOn:animated:`** — хук UISwitch в
   MPSettingsHooks.xm читает associated object по СВОЕМУ `static char kToggleKey`,
   а MPSettingsToggle сохраняет себя по СВОЕМУ (другой адрес). Хук всегда получает
   nil → состояние оверлея не обновляется, когда система/PS меняет свитч без лейаута.
   → фикс: класс-метод `+syncExistingForSwitch:` (не создающий оверлей), вызов из хука.
2. **Утечка CGColorSpace в `mp_imageLooksBlue:`** — `CGColorSpaceCreateDeviceRGB()`
   никогда не освобождается; вызывается на каждом глубоком проходе по ячейкам.
3. **Строка «Другая…» в Wi-Fi после переиспользования ячейки сети** может остаться
   с видимыми полосками уровня/замком: `mp_styleNetworkRow` выходит по
   `nameLabel == nil` ДО скрытия наших тег-вьюх.
4. Мелочь: `field.placeholder = field.placeholder` (self-assignment) в styleTextField.

# Аудит приложения «Настройки» (MetroPhone)

Дата: 26.10.2026 · прошивка iOS 6.1.3 (iPhone 4) · версия твика 0.15.6

Метод: экран открывался по схеме `prefs:root=<идентификатор>`, затем снимался дамп
дерева вьюх (классы, кадры, тексты) и PNG. Дамп — `/var/mobile/Library/Caches/metrophone/dump-*.txt`,
снимки — `screenshots/sweep/shot*-*.png`.

## Правила оформления

- **Корневое меню** — без иконок: плоский WP-список, только текст и контролы.
- **Внутренние страницы** — иконки, которые объявила строка, заменяются на глифы
  Windows Phone (шрифт Metro UI Icons, MIT). Строкам без иконки ничего не добавляется.
- Подпись заголовка страницы — крупная, строчными; кнопки панели — 12 pt Medium.

## Что исправлено в этой итерации

1. В корневом меню убраны иконки (флаг `MPSettingsIconsHidden` выставляется по глубине навигации).
2. Иконки внутренних страниц заменены на глифы WP; таблица глифов расширена по смыслу строк
   (геолокация, контакты, календарь, напоминания, фото, камера, музыка, видео, почта, звук,
   яркость, хранилище, iCloud, VPN/пароль, Twitter, темы, восстановление, статус, карты).
3. Кнопка панели больше не стилизуется как заголовок: хук `MPApplyMetroTitle` не заходит
   в `UIControl`, поэтому «Изменить» не обрезается.

## Осталось

- Ползунок: правый трек — обрубок (нужен растягиваемый образ трека).
- Заголовок секции «Сортировать программы:» имеет ширину 320 при x=16 (вылет 16 pt за экран);
  визуально не заметно, но лучше привести к 288.
- Страницы «Не беспокоить» и «Карты» не открылись по URL — нужен ручной проход.
